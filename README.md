# AI Klasifikasi Buah Naga dan Mangga

Aplikasi web berbasis Streamlit untuk mengklasifikasikan gambar buah menjadi Buah Naga atau Mangga menggunakan model CNN berformat H5.

## Fitur
- Upload gambar JPG, JPEG, atau PNG
- Prediksi jenis buah: Buah Naga atau Mangga
- Menampilkan tingkat keyakinan prediksi
- Model H5 diambil otomatis dari Google Drive

## Teknologi
- Python
- TensorFlow / Keras
- Streamlit
- Google Drive
- gdown

## Menjalankan secara lokal
```bash
pip install -r requirements.txt
streamlit run app.py
