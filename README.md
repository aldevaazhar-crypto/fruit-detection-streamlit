# AI Deteksi Gambar Buah

Aplikasi web berbasis Streamlit untuk mengklasifikasikan gambar apakah termasuk buah atau bukan buah menggunakan model CNN berformat H5.

## Fitur

- Upload gambar JPG, JPEG, atau PNG
- Prediksi gambar buah atau bukan buah
- Menampilkan tingkat keyakinan prediksi
- Model H5 diambil otomatis dari Google Drive

## Teknologi

- Python
- TensorFlow / Keras
- Streamlit
- Google Drive
- gdown

## Cara Menjalankan

```bash
pip install -r requirements.txt
streamlit run app.py
